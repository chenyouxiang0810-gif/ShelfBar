# ShelfBar v1.0 Beta

First Public Beta

## Main Features

- Universal Drop for files, images, text and URLs
- AirDrop Drop Zone
- Touch Bar Shelf
- Folder Stack and Nested Stack
- Native Finder icons and QuickLook thumbnails
- Dock-like reorder and smooth touch drag
- Drag Back Out to Finder with FilePromise copy
- Floating Shelf Button
- Menu Bar Mode
- Light / Dark / Auto theme
- Temporary item cleanup

## Known Limitations

- Intel Mac with physical Touch Bar required for the full experience.
- Uses private Touch Bar APIs.
- Current beta is not notarized unless the release is signed and notarized with a Developer ID certificate.
- App Store distribution is not expected.

## Gatekeeper Note

If macOS says ShelfBar cannot be verified, open System Settings → Privacy & Security → Open Anyway.

Only bypass Gatekeeper for builds downloaded from the official GitHub Release.

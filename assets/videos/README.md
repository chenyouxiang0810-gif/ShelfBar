Place real ShelfBar feature recordings here. The page checks these filenames
automatically on load, so you can drop a recording into this folder and refresh
the local preview.

Preferred filenames:
- files.mp4
- search.mp4
- recent.mp4
- clipboard.mp4
- clips.mp4
- pin.mp4
- stack.mp4
- drag-drop.mp4
- hover.mp4

Optional alternates:
- files.webm / files.mov
- search.webm / search.mov
- recent.webm / recent.mov
- clipboard.webm / clipboard.mov
- clips.webm / clips.mov
- pin.webm / pin.mov
- stack.webm / stack.mov
- drag-drop.webm / drag-drop.mov
- hover.webm / hover.mov

The Touch Bar area uses these keys:

{
  "files": "assets/videos/files.mp4",
  "search": "assets/videos/search.mp4",
  "recent": "assets/videos/recent.mp4",
  "clipboard": "assets/videos/clipboard.mp4",
  "clips": "assets/videos/clips.mp4",
  "pin": "assets/videos/pin.mp4",
  "stack": "assets/videos/stack.mp4",
  "drop": "assets/videos/drag-drop.mp4",
  "hover": "assets/videos/hover.mp4"
}

You only need to edit manifest.json if you want to use different filenames.

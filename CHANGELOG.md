# Changelog

## v1.0.0-beta.1 - 2026-07-09

First public beta preparation.

### Added

- Touch Bar file shelf for Intel MacBook Pro with physical Touch Bar.
- Universal Drop for files, images, text and URLs.
- AirDrop Drop Zone.
- Finder-style native icons and QuickLook thumbnails.
- Folder Stack and Nested Stack support.
- Dock-like reorder and drag interaction.
- Drag Back Out to Finder using FilePromise copy fulfillment.
- MouseBridge for cursor-driven Touch Bar interaction.
- Floating Shelf Button.
- Menu Bar Mode and optional Dock visibility.
- Light, Dark and Auto themes.
- Temporary item cleanup for generated ShelfBar files.
- Polished DMG packaging.
- GitHub release preparation files.
- GitHub Pages site under `docs/`.
- Homebrew Cask draft under `Packaging/homebrew/`.

### Known limitations

- Requires an Intel Mac with physical Touch Bar for the core experience.
- Uses private Touch Bar APIs.
- Current local build is not Apple notarized.
- Homebrew Cask is prepared but not submitted.
